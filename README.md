# Arch Linux Dotfiles

My OWN Arch Linux desktop configuration.

## Desktop

- Window manager: SwayFX
- Terminal: Foot
- Shell: Zsh + Powerlevel10k
- Bar: Waybar
- File manager: Thunar
- Text editor: Xed

## Theme

- Dark gray and black
- GTK dark mode
- Bibata cursor

## Restore

Back up existing configuration files before copying these files into `~/.config/`.

Some settings and package dependencies may need adjusting for different machines.at the same time
